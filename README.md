# TG SI Geography Quiz — GitHub Pages లో Free గా Live చేయడం

**అన్నీ తెలుగులో** — 1044 ప్రశ్నలు, 59 టాపిక్‌లు, 67 సెట్‌లు (ప్రతి సెట్‌లో 30 ప్రశ్నలు).
ప్రతి ప్రశ్న తర్వాత వివరణాత్మక వివరణ (కాన్సెప్ట్ + గుర్తుంచుకునే ట్రిక్ + మూలం) ఉంటుంది.

## ఫైళ్లు
- `index.html` — యాప్ (డిజైన్ + క్విజ్ ఇంజిన్)
- `questions.js` — 1044 ప్రశ్నలు, టాపిక్ వారీగా, తెలుగులో
- `concepts.js` — ప్రతి టాపిక్‌కు వివరణ, కీ పాయింట్లు, ట్రిక్
- `.nojekyll` — GitHub Pages కోసం

## GitHub Pages లో Live చేయడం (5 నిమిషాలు, Free)

1. GitHub లో కొత్త Repository సృష్టించండి (ఉదా: `tg-si-geography-quiz`). Public గా పెట్టండి.
2. ఈ ఫోల్డర్‌లోని **అన్ని ఫైళ్లను** ఆ Repository లోకి అప్‌లోడ్ చేయండి (Add file → Upload files, లేదా git push).
   - ముఖ్యం: `index.html` Repository యొక్క root లో ఉండాలి.
3. Repository లో **Settings → Pages** కి వెళ్ళండి.
4. **Build and deployment → Source** లో `Deploy from a branch` ఎంచుకోండి.
5. **Branch** లో `main`, ఫోల్డర్‌లో `/ (root)` ఎంచుకుని **Save** నొక్కండి.
6. 1–2 నిమిషాల్లో పైన Green టిక్‌తో మీ లింక్ వస్తుంది:
   `https://<మీ-username>.github.io/tg-si-geography-quiz/`
7. ఆ లింక్‌ను విద్యార్థులకు పంపండి — ఎవరైనా, ఎలాంటి Login లేకుండా వాడవచ్చు.
